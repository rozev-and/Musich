# MUSICH на Windows — без Docker

Обычный установщик: скачал `MUSICH-Setup-<версия>.exe`, нажал «Далее», в браузере открылся MUSICH.

## Что делает установщик

- Ставит программу в `C:\Program Files\MUSICH`: свой Node внутри, отдельно ничего ставить не нужно.
- Запускает сервер в фоне при старте компьютера, даже до входа в Windows (Планировщик заданий, задача `MUSICH`). Работает от твоего имени и без прав администратора: видит только твои файлы, папку данных другие учётки Windows не откроют. Упал — поднимется сам.
- Открывает сервер для домашней и рабочей сети (правило брандмауэра `MUSICH`). В общественном Wi-Fi сервер закрыт.
- Кладёт ярлык «MUSICH» в «Пуск» — он открывает `http://localhost:2290`.

## Где что лежит

| Что | Где |
|---|---|
| Программа | `C:\Program Files\MUSICH` |
| База, обложки, миниатюры | `C:\ProgramData\MUSICH\data` |
| Первая папка музыки | `C:\ProgramData\MUSICH\music` — свои папки добавляются в «Настройки → Папки с музыкой» |
| Журнал | `C:\ProgramData\MUSICH\logs\musich.log` |

Удаление программы («Установка и удаление программ») снимает задачу и правило брандмауэра, а данные в `C:\ProgramData\MUSICH` и музыку не трогает. Переустановка поверх — с теми же данными.

## Телефон

Дома телефон находит сервер сам. Если сеть Windows отмечена как «Общедоступная», телефон его не увидит: поменяй её на «Частную» в параметрах Wi-Fi.

## Сжатие качества

Для «Качество → 320/128» нужен ffmpeg — в установщик он не входит (это ещё 200 МБ). Поставь его сам (`winget install Gyan.FFmpeg`) или положи `ffmpeg.exe` в `C:\Program Files\MUSICH`. Без него музыка играет в оригинале.

## Сборка установщика

Нужны Windows x64, Node и Inno Setup 6 (`winget install JRSoftware.InnoSetup`):

```
node deploy/windows/build.mjs
```

Готовый файл — `deploy/windows/out/MUSICH-Setup-<версия>.exe`. Версия берётся из `server/package.json`.
`--stage-only` собирает только папку программы (`deploy/windows/out/stage`) — проверить сервер без установки:
`MUSICH_HOME=<временная папка> MUSICH_PORT=2391 out/stage/node.exe out/stage/launcher.mjs`.
